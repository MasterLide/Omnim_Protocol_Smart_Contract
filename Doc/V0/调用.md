定版V0,无治理，初始绿色子币，支持模板扩展，有奖励

## 调用
### 1.发行子币
#### a.在母币授权工厂合约
#### b.在工厂合约提交子币信息
```
在工厂合约执行方法：
proposeSubToken(
        string memory name, //名称
        string memory symbol, //符号       
        uint8 decimals, //精度
        uint256 totalSupply, //发行量
        address initialOwner, //管理者
        uint256 pledgeAmount, //质押母币数
        uint256 liquidityAmount //注入底池母币数
    )
```
母币授权数量必须大于等于（质押母币数 + 注入底池母币数），且达到门槛值
### 2.取消发行子币
在子币上市前，可取消发行子币，赎回授权的母币。
```
在工厂合约执行方法：
withdraw(
    uint256 id //子币发行ID
    )
```
### 3.子币上市
确认子币上市，授权的母币将被使用，以后赎回有一定门槛。
```
在工厂合约执行方法：
默认子币模板
executeApplication(
    uint256 id, //子币发行ID
    bool canStake, //是否接受质押
    uint256 _point //注入底池子币比例
    ) 
或
使用指定子币模板
executeApplication(
    uint256 id, //子币发行ID
    bool canStake, //是否接受质押
    uint256 _point, //注入底池子币比例
    uint8 modelId //模板id
    ) 
        
```
### 4.赎回质押
在子币上市后，达到门槛，可赎回子币质押的母币。赎回后子币社区将无母币收益
```
在工厂合约执行方法：
withdrawStake(
    uint256 id //子币发行ID
    )
```
### 5.质押子币LP获取母币收益
#### a.在去中心交易所获取子币LP
#### b.在子币LP合约授权子币vetoken合约
#### c.质押子币LP获取子币vetoken
```
在子币vetoken合约执行方法：
stake(
    uint256 amount, //质押数量
    address receiver, //接受地址 
    address delegatee  //授权地址（投票权，用于治理）    
    )
```
#### d.提取母币收益
```
在子币子矿池合约执行方法：
claimMyMines(
    address account //用户地址 
    )
```
### 6.销毁子币vetoken赎回子币LP
当达到锁定时间点后可执行
```
在子币vetoken合约执行方法：
withdraw(
    uint256 amount //销毁数量  
    )
```

## 特别操作

### TokenFactoryV0合约扩展控制
TokenFactoryV0合约预留扩展控制方法，可控制TokenFactoryV0合约发起任意操作
```
executeOperations(
        address  targets,
        uint256  values,
        bytes memory calldatas
    )
//DEFAULT_ADMIN_ROLE权限，控制TokenFactoryV0合约发送values主链币到targets，并发起calldatas调用

```
### MinerPool保险权限使用
MinerPool预留保险权限，可转移MinerPool持有的任意代币（非主链币）
```
saveToken(address _token, address _receiver, uint256 _amount)//保险权限，转移MinerPool持有的_amount数量_token代币到_receiver
```
### 矿池合约主动触发收益发放，清理积累数据
当矿池合约长时间没有用户提取收益/质押/赎回时，累积待处理数据可能导致gas不足失败，可主动触发收益发放，清理积累数据
```
doMine() //主动触发收益发放，先主矿池，后子矿池
```
