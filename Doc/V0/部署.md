#  V0版本

定版V0,无治理，初始绿色子币，支持模板扩展，有奖励

## 使用的合约文件

| 合约名 | 路径/文件名 | 简述 | 备注 |
| ------ | ------ | ------ | ------ |
| VeToken | contracts/VeToken.sol   | 质押映射币 | 模板/母币映射 |
| TokenFactoryV0 | contracts/TokenFactoryV0.sol | 工厂合约 | 含子币数据 | 
| SubTokenV0 | contracts/SubTokenV0.sol | 子币模板 | - |
| MinerPool | contracts/MinerPool.sol| 主矿池合约 | - |
| SubMinerPoolV0 | contracts/SubMinerPoolV0.sol| 子矿池合约模板 | - |
| MainToken | contracts/MainToken.sol | 母币 | - |

## 部署

### 1.部署合约/模板

#### 母币
部署contracts/MainToken.sol的MainToken合约。
构造参数：
uint256 _initialSupply **初始流通量** , address initialOwner **初始owner**
#### 母币质押映射币
部署contracts/VeToken.sol的VeToken合约。
构造参数：无
#### 主矿池合约
部署contracts/MinerPool.sol的MinerPool合约。
构造参数：无
#### 工厂合约
部署contracts/TokenFactoryV0.sol的TokenFactoryV0合约。
构造参数：无
#### 子矿池合约模板
部署contracts/SubMinerPoolV0.sol的SubMinerPoolV0合约。
构造参数：无
#### 子币模板
部署contracts/SubTokenV0.sol的SubTokenV0合约。
构造参数：无


### 2.合约初始化/实例化，初始设置

#### 使用基础模式（不可升级）

a.初始化各合约

```
在母币质押映射币合约执行方法
initialize(   
        string memory _name, //名称
        string memory _symbol, //符号
        address _owner, //初始owner
        address _assetToken, //质押币（母币地址）
        uint256 _matureAt, //初始质押锁定时间（单位：秒）
        bool _canStake  //是否接受质押（除初始质押）
        )

```
```
在主矿池合约执行方法
initialize(
        address mineToken_,//挖取代币（母币地址）
        address stakeContract_,//质押合约（母币质押映射币地址）
        uint256 firstDayMines,//首日出矿量
        uint256 decayPerDay,//每日递减量
        uint16 userMineBase,//基础权重值
        uint16 userMineAddPerDay//每日递增权重值
    )
```
```
在工厂合约执行方法
initialize(
        address tokenImplementation_, //子币模板合约地址
        address assetToken_,    //母币地址
        address assetVeToken_,  //母币质押映射币地址
        address veTokenImplementation_,//质押映射币模板（母币质押映射币地址）
        address minerPoolImplementation_ //子矿池模板合约地址
    )

```

b.初始设置
```
在母币质押映射币合约设置主矿池，执行方法
setMiner(
    address _miner //主矿池合约地址
    )
```
```
在工厂合约设置去中心交易所路由合约，执行方法
setUniswapRouter(
        address router //使用的去中心交易所路由合约地址
    )
```
```
在主矿池合约设置GOV_ROLE权限（管理权限）：
调GOV_ROLE()方法，获取GOV_ROLE权限标识
执行授权方法
grantRole(
    bytes32 role, //权限标识
    address account //获得权限地址
    )
```

### 3.初始操作
```
在母币质押映射币合约进行初始质押：
在母币合约执行approve()方法，授权母币质押映射币合约质押数量
在母币质押映射币合约执行质押方法
stake(
    uint256 amount, //质押数量
    address receiver, //持有地址（收益权）
    address delegatee //委托地址（投票权）
    )
```
```
开启主矿池前/产生第一笔收益前，在母币合约增发/转账一定数量母币给主矿池合约
ps：如主矿池合约持有母币不足将导致收益提取失败

```
```
在使用的去中心交易所创建 母币&稳定币 交易对并注底池
ps：开放的母币获取渠道，如不开放可不进行该操作

```
